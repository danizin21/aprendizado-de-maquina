# Projetos de Aprendizado de Máquina

Repositório destinado à organização dos meus estudos e projetos desenvolvidos na área de **Aprendizado de Máquina (Machine Learning)**.

Aqui estão reunidos projetos acadêmicos e práticos envolvendo algoritmos de Machine Learning, pré-processamento de dados, treinamento e avaliação de modelos.

## Projetos

### 01. Regressão Linear — Qualidade de Vinhos

Implementação de um modelo de Regressão Linear Múltipla do zero, utilizando Gradiente Descendente, para analisar a relação entre características físico-químicas e a qualidade de vinhos tintos.

**Principais conceitos:**
- Regressão Linear Múltipla
- Gradiente Descendente
- Pré-processamento e padronização de dados
- Divisão entre treino, validação e teste
- Métricas de avaliação: MAE, MSE e MAPE

[ Acessar projeto](./01-regressao-linear-qualidade-vinhos/)

### 02. Rede Neural — Previsão de Sobrevivência no Titanic

Desenvolvimento de uma Rede Neural Artificial utilizando TensorFlow e Keras para prever a sobrevivência de passageiros do Titanic.

**Principais conceitos:**
- Redes Neurais Artificiais (MLP)
- Pré-processamento de dados
- Tratamento de valores ausentes
- One-Hot Encoding
- Padronização com StandardScaler
- Early Stopping
- Avaliação de modelos de classificação

[ Acessar projeto](./02-rede-neural-titanic/)
