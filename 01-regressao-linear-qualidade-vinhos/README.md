# Regressão Linear — Qualidade de Vinhos

## Sobre o projeto

Este projeto implementa um modelo de Regressão Linear Múltipla do zero, utilizando o algoritmo de Gradiente Descendente para ajustar os parâmetros do modelo.

O objetivo é analisar a relação entre as características físico-químicas dos vinhos e sua qualidade.

## Técnicas utilizadas

- Regressão Linear Múltipla
- Gradiente Descendente
- Padronização dos dados
- Divisão dos dados em treino, validação e teste
- Avaliação de desempenho com MAE, MSE e MAPE

## Dataset

Foi utilizado o conjunto de dados Wine Quality — Red Wine, que contém informações físico-químicas de vinhos tintos e suas respectivas avaliações de qualidade.

## Resultados

O modelo foi avaliado utilizando diferentes métricas de erro. Na execução registrada no notebook, o MSE no conjunto de teste foi de aproximadamente 0,3898.
